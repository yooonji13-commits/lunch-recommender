# 오늘 뭐 먹지? — 점심 메뉴 추천 웹앱

내 위치 기준 반경(1km / 5km / 10km) 안의 음식점을 찾아주고, 랜덤 추천·즐겨찾기·최근 본 가게 기능을 제공하는 홈스크린 웹앱입니다.

## 1. 카카오 REST API 키 발급 (필수)

이 앱은 **카카오 로컬 API**로 주변 음식점 데이터를 가져옵니다. 무료이며 발급에 5분 정도 걸립니다.

1. https://developers.kakao.com 접속 → 로그인 → **내 애플리케이션 추가**
2. 앱 생성 후 **앱 키 > REST API 키** 복사
3. 좌측 메뉴 **플랫폼 > Web 플랫폼 등록**에 아래 주소들을 등록
   - 로컬 테스트용: `http://localhost:3000` (아래 3번 실행 방법에서 쓰는 포트와 맞추기)
   - 실제 배포 도메인 (예: `https://내아이디.github.io`) — 배포 후 추가
4. 이 프로젝트의 [js/config.js](js/config.js) 파일을 열어 아래처럼 키를 채워 넣기

```js
const KAKAO_REST_API_KEY = "여기에_발급받은_REST_API_키";
```

> 키를 넣지 않으면 화면 상단에 설정 안내 배너가 뜹니다.

## 2. 로컬에서 열어보기

`index.html`을 파일로 그냥 더블클릭해서 열면 위치정보(GPS)와 API 호출이 브라우저 보안 정책 때문에 막힐 수 있습니다. 아래처럼 간단한 로컬 서버로 열어주세요. (Node.js가 이미 설치되어 있어야 합니다.)

```bash
npx serve . -l 3000
```

실행 후 브라우저에서 `http://localhost:3000` 접속 → 정상 동작 확인.
(이때 `http://localhost:3000`을 위 1-3단계 카카오 Web 플랫폼에 등록해야 API가 정상 호출됩니다.)

## 3. 아이폰 홈 화면에 앱처럼 추가하기

홈 화면 추가는 **https 주소**로 배포된 뒤에 진행하는 걸 권장합니다(로컬 주소는 다른 기기에서 열리지 않고, 위치정보도 https에서 가장 안정적으로 동작합니다).

1. 아래 "4. 배포하기"로 무료 https 주소를 만든다
2. 아이폰 **사파리**로 그 주소 접속
3. 하단 공유 버튼(⬆️) → **홈 화면에 추가**
4. 이름 확인 후 추가 → 홈 화면에 앱 아이콘 생성, 탭하면 주소창 없이 앱처럼 실행됨

## 4. 배포하기 (예: GitHub Pages, 무료)

1. 이 폴더로 깃 저장소 생성 후 GitHub에 업로드
2. 저장소 **Settings > Pages**에서 Branch를 `main` (또는 사용 브랜치)로 설정 후 저장
3. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 주소 생성됨
4. 이 주소를 카카오 개발자센터 Web 플랫폼에 등록 (1-3단계)
5. 아이폰 사파리로 접속 → 홈 화면에 추가

Vercel, Netlify 등을 선호하면 그 서비스에 이 폴더를 그대로 배포해도 됩니다 (정적 파일이라 별도 빌드 과정 없음).

## 기능 요약

- **반경 검색**: 1km / 5km / 10km 중 선택, 현재 위치 기준 거리순 정렬
- **목록**: 최소 10개 표시, "더보기" 버튼으로 10개씩 추가 로드 (최대 30개)
- **종류 필터**: 한식/중식/일식/양식/분식/카페/치킨/고기/아시안/패스트푸드 칩 필터
- **상세 정보**: 이름, 카테고리, 거리, 주소, 전화, 카카오맵 상세보기(메뉴·별점·영업시간·사진은 카카오맵 페이지에서 확인), 길찾기, 전화 걸기, 즐겨찾기
- **랜덤 추천**: "오늘 뭐 먹지?" 버튼으로 현재 목록 중 무작위 추천, "다른 메뉴 뽑기"로 재추첨(직전 결과는 제외)
- **즐겨찾기**: 하트를 눌러 저장, 별도 탭에서 언제든 확인 (브라우저에 저장되어 앱 재실행해도 유지)
- **최근 본 가게**: 상세보기를 눌렀던 가게 자동 기록
- **PWA**: 홈 화면 아이콘, 오프라인에서도 앱 뼈대(화면 레이아웃) 로딩 가능
- **다크 모드**: 기기 설정에 따라 자동 전환

## 참고: 메뉴판 사진·개별 메뉴 가격·별점에 대해

카카오 로컬 API 자체는 이름/주소/전화/거리 정도만 제공하고, 개별 메뉴·가격표·별점 데이터는 공식 API로 제공되지 않습니다. 그래서 상세 화면에서 "카카오맵에서 상세보기" 버튼을 누르면 해당 가게의 카카오맵 페이지(실제 등록된 메뉴 사진, 리뷰, 별점, 영업시간)로 바로 연결되도록 만들었습니다.
